## Features

    <li>Multiline editing with three sizes and a value model.</li>
    <li>Native textarea attributes and browser editing behaviour.</li>
</ul>

## Native textarea attributes

Bind `v-model` or supply an initial defaultValue. Native attributes such as rows, maxlength, name, required, disabled, readonly and placeholder are forwarded to the textarea. Use a linked label and describe hints or errors with aria-describedby.
