## Features

    <li>Three sizes with a controlled or initial value.</li>
    <li>Native input attributes and browser editing behaviour.</li>
</ul>

## Native input attributes

Bind `v-model` for a controlled value or use `defaultValue` for an initial value. Native attributes such as type, name, placeholder, autocomplete, required, disabled and readonly remain available, together with native input and blur events. Associate a Label with the input id or provide an accessible name.
