    <li>A persistent pressed state for an independent action.</li>
    <li>Three sizes, theme colours and icon-only presentation.</li>
</ul>

## Pressed state and appearance

Toggle exposes a persistent pressed state through its model and aria-pressed. The default variant uses a light selected surface, dark uses a dark selected surface, and outline remains a compatibility alias for default. Supply an accessible name for icon-only content.
